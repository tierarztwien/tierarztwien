# Bilder fuer die Sektion "Aktuelles"

Hier liegen die Fotos der News- und Event-Eintraege.

- Vor dem Hochladen auf **max. 1600 px Breite** verkleinern (Netlify liefert sie
  unveraendert aus, ein 8-MB-Handyfoto bremst die ganze Seite).
- Dateiname sprechend, klein, mit Datum: `2026-11-tag-der-offenen-tuer-01.jpg`
- Jedes Bild braucht im HTML einen `alt`-Text (Barrierefreiheit und Google).
